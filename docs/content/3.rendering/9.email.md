The `@comark/email` package converts Markdown documents into responsive, inline-styled HTML compatible with all major email clients. It uses [Maizzle](https://maizzle.com) (v4) and Tailwind CSS to inline utility classes, purge unused styles, and produce Outlook-safe output.

## Installation

::code-group

```bash [pnpm]
pnpm add @comark/email @maizzle/framework
```

```bash [npm]
npm install @comark/email @maizzle/framework
```

::

`@maizzle/framework` is a required direct dependency that handles CSS inlining and Tailwind compilation.

## Frontmatter configuration

Control email metadata and theme via the `email:` key in your document frontmatter:

```markdown
---
email:
  subject: "Your order #1234 has shipped!"
  previewText: "Track your package delivery status."
  theme:
    primary: "#0066cc"
    background: "#f4f5f7"
---

# Document content here
```

| Key | Type | Description |
|-----|------|-------------|
| `subject` | `string` | Email subject line. Returned in `EmailRenderResult`. |
| `previewText` | `string` | Short preview shown in inbox before the body. Injected as a hidden preheader. |
| `theme` | `Record<string, string>` | Color overrides mapped to Tailwind `theme.extend.colors`. |

## Render email HTML

`renderEmail` is the main entry point. It parses the Markdown, assembles the HTML, runs Maizzle, and returns `{ html, subject, previewText, errors }`.

```typescript
import { renderEmail } from '@comark/email'

const { html, subject, previewText, errors } = await renderEmail(`
---
email:
  subject: "Hello!"
  previewText: "Read this message."
  theme:
    primary: "#0066cc"
---

# Hello

Welcome to Comark Email.

::email-button{href="https://example.com" class="bg-primary text-white py-3 px-6"}
Get Started
::
`)

// Pass output directly to your email provider
await sendEmail({ to: user.email, subject, html })
```

### Reusable renderer

Use `createEmailRenderer` when you need to render multiple documents with the same configuration. The underlying parser is initialized once.

```typescript
import { createEmailRenderer } from '@comark/email'

const render = createEmailRenderer({
  email: { theme: { primary: '#0066cc' } },
})

const result = await render(markdownString)
```

### From a pre-parsed document

```typescript
import { parseMarkdown } from 'comark'
import { renderEmailFromDocument } from '@comark/email'

const doc = await parseMarkdown('---\nemail:\n  subject: Hello\n---\n# Hi')
const { html, subject } = await renderEmailFromDocument(doc)
```

## Email components

The following built-in components are always active when using `renderEmail` or `renderEmailFromDocument`.

### `::email-button`

Renders a link button as an `<a>` element. Maizzle inlines the Tailwind classes after rendering.

```markdown
::email-button{href="https://example.com/confirm" class="bg-primary text-white py-3 px-6 rounded-lg"}
Confirm Email
::
```

Supported attributes:

| Attribute | Description |
|-----------|-------------|
| `href` | Link destination. Defaults to `#`. |
| `class` | Tailwind utility classes. |

### `::email-columns`

Renders a table-based multi-column layout. Each direct child block becomes a table cell.

```markdown
::email-columns{class="gap-4"}
**Left** column content.

**Right** column content.
::
```

### `::email-divider`

Renders a table-based horizontal rule for consistent display across email clients.

```markdown
::email-divider{class="border-gray-200 my-4"}
::
```

## Custom Tailwind configuration

Pass a Tailwind configuration object via `tailwindConfig` to extend or override the defaults:

```typescript
import { renderEmail } from '@comark/email'
import tailwindcssPresetEmail from 'tailwindcss-preset-email'

const { html } = await renderEmail(markdown, {
  tailwindConfig: {
    presets: [tailwindcssPresetEmail],
    theme: {
      extend: {
        fontFamily: {
          sans: ['Inter', 'Arial', 'sans-serif'],
        },
      },
    },
  },
})
```

## Custom Maizzle options

Forward any Maizzle render options via `maizzleOptions`. These are merged last and override computed config:

```typescript
await renderEmail(markdown, {
  maizzleOptions: {
    css: { shorthand: true },
  },
})
```

## Error handling

Maizzle compilation errors are collected into the `errors` array instead of thrown. The un-inlined assembled HTML is returned as fallback so callers always receive usable output.

```typescript
const { html, errors } = await renderEmail(markdown)

if (errors.length > 0) {
  console.error('Email compilation errors:', errors)
}
```

## Plugins

All core Comark plugins are available via `@comark/email/plugins/*`:

```typescript
import { renderEmail } from '@comark/email'
import shiki from '@comark/email/plugins/shiki'
import math, { Math } from '@comark/email/plugins/math'
import binding, { Binding, If } from '@comark/email/plugins/binding'

const { html } = await renderEmail(markdown, {
  plugins: [shiki(), math()],
  components: { Math, Binding, If },
})
```
