[Streamdown](https://streamdown.ai) is Vercel's React markdown renderer for AI streaming, built on `react-markdown`. Comark ships a drop-in `<Streamdown>` component backed by its own parser — so you keep the same component API while gaining a faster streaming engine (source-level [`autoClose`](/api/auto-close) plus incremental node reuse), [Comark components](/syntax/components), and a zero-config stylesheet.

::callout{icon="i-lucide-info" color="info"}
This is a drop-in for Streamdown's **component usage**, not for arbitrary `react-markdown` plugin pipelines. If you pass custom `remarkPlugins` / `rehypePlugins`, see [Not supported](#not-supported) below.
::

---

## Quick start

Install Comark alongside the optional renderers you use, and swap the import.

::code-group

```bash [pnpm]
pnpm add @comark/react shiki katex beautiful-mermaid
```

```bash [npm]
npm install @comark/react shiki katex beautiful-mermaid
```

::

Import the stylesheet once (it replaces Streamdown's Tailwind `@source` setup):

```tsx [app/layout.tsx]
import '@comark/react/streamdown.css'
```

Then change the import — the markup stays the same:

::code-group

```tsx [Before]
import { Streamdown } from 'streamdown'

export function Message({ text }: { text: string }) {
  return <Streamdown>{text}</Streamdown>
}
```

```tsx [After]
import { Streamdown } from '@comark/react/streamdown'

export function Message({ text }: { text: string }) {
  return <Streamdown>{text}</Streamdown>
}
```

::

## Prop mapping

Most props carry over unchanged. The table below covers the common surface.

| Streamdown | Comark `<Streamdown>` | Notes |
|------------|------------------------|-------|
| `children` | `children` / `markdown` | Same |
| `mode` | `mode` | `'streaming'` (default) or `'static'` |
| `parseIncompleteMarkdown` | `parseIncompleteMarkdown` | Maps to `autoClose` (default `true`) |
| `className` | `className` | Same |
| `components` | `components` | Same idea — map a tag to a component. Also supports [Comark components](/syntax/components) |
| `controls` | `controls` | `true` or `{ code }` — toggles the copy/download bar |
| `caret` | `caret` | `'block'` (default), `'circle'`, `'none'` |
| `allowedImagePrefixes` | `allowedImagePrefixes` | Security is **on by default** |
| `allowedLinkPrefixes` | `allowedLinkPrefixes` | — |
| `defaultOrigin` | `defaultOrigin` | — |
| `mermaid` | `mermaid` | Mermaid theme config |
| `shikiTheme` | `shikiTheme` | **Takes theme registration objects, not names** — see below |

### `shikiTheme`

This is the one prop that isn't a verbatim copy. Streamdown accepts theme **names**; Comark's highlighter takes theme **registration objects**. Import them from `@shikijs/themes`:

::code-group

```tsx [Streamdown]
<Streamdown shikiTheme={['github-light', 'github-dark']}>
  {text}
</Streamdown>
```

```tsx [Comark]
import githubLight from '@shikijs/themes/github-light'
import githubDark from '@shikijs/themes/github-dark'

<Streamdown shikiTheme={[githubLight, githubDark]}>
  {text}
</Streamdown>
```

::

Omit `shikiTheme` entirely to use Comark's bundled defaults.

## Styling

Streamdown styles via Tailwind classes baked into its components (materialized with an `@source` directive) and themed through shadcn CSS variables. Comark ships a **plain, dependency-free stylesheet** instead.

| | Streamdown | Comark |
|---|------------|--------|
| Delivery | Tailwind `@source` scan | `import '@comark/react/streamdown.css'` |
| Tailwind required | Yes | No |
| Theming | shadcn variables (`--primary`, …) | `--comark-*` variables on `.comark-content` |
| Overrides | `data-streamdown` attributes | single-class selectors / CSS variables |

Re-theme by overriding the variables:

```css
.comark-content {
  --comark-link: #7c3aed;
  --comark-border: #e2e8f0;
  --comark-code-bg: #0f172a;
}
```

## Incomplete markdown

Streamdown completes unterminated tokens with [`remend`](https://www.npmjs.com/package/remend); Comark uses [`autoClose`](/api/auto-close). Both are pre-parse, string-to-string transforms — the behavior is equivalent, and it's on by default. Toggle it with `parseIncompleteMarkdown={false}` (or `options={{ autoClose: false }}` on `<Comark>`).

## Not supported

These Streamdown props have no Comark equivalent today. Most are cosmetic or `react-markdown`-specific:

| Prop | Reason |
|------|--------|
| `remarkPlugins`, `rehypePlugins` | Comark uses its own [plugin system](/plugins), not the remark/rehype pipeline |
| `prefix` | Tailwind-prefix concern — Comark ships plain CSS |
| `animated`, `isAnimating` | The caret animates automatically while `mode="streaming"` |
| `lineNumbers`, `translations`, `icons` | Not implemented |
| `linkSafety` | Links are sanitized by the security plugin, but there is no confirmation modal |

If you rely on custom remark/rehype plugins, replace them with the [equivalent Comark plugin](/plugins) where one exists, or keep using Streamdown for that surface.

## Why switch

- **Faster streaming** — `autoClose` is a regex-free O(n) pass, and completed nodes are cached and never re-parsed across chunks.
- **No lookbehind** — `autoClose` avoids the regex lookbehind that breaks `remend` on older Safari/iOS.
- **Components** — author `::alert{}` and other [Comark components](/syntax/components) directly in the stream.
- **Zero-config styling** — one CSS import, no Tailwind setup.
- **Same engine everywhere** — the parser also renders to [Vue](/rendering/vue), [Svelte](/rendering/svelte), [HTML](/rendering/html), and the [terminal](/rendering/ansi).
