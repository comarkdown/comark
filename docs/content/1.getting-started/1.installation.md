## Install Comark

::code-group
```bash [pnpm]
# Vue
pnpm add @comark/vue
# React
pnpm add @comark/react
# HTML
pnpm add comark
```

```bash [npm]
# Vue
npm install @comark/vue
# React
npm install @comark/react
# HTML
npm install comark
```

```bash [yarn]
# Vue
yarn add @comark/vue
# React
yarn add @comark/react
# HTML
yarn add comark
```

```bash [bun]
# Vue
bun add @comark/vue
# React
bun add @comark/react
# HTML
bun add comark
```
::

## Quick Start

Pick your framework and get rendering in seconds.

### Vue

::code-group
```vue [App.vue]
<script setup lang="ts">
import { Comark } from '@comark/vue'

const content = `# Hello World

This is **markdown** with a custom component:

::alert{type="info"}
Welcome to Comark!
::
`
</script>

<template>
  <Comark>{{ content }}</Comark>
</template>
```

```html [Output]
<h1 id="hello-world">Hello World</h1>
<p>This is <strong>markdown</strong> with a custom component:</p>
<div class="alert alert-info">
  <p>Welcome to Comark!</p>
</div>
```
::

::callout{color="warning" icon="i-lucide-triangle-alert"}
When using async plugins (like syntax highlighting), wrap `<Comark>` in a `<Suspense>` component. See [Vue Rendering](/rendering/vue) for details.
::

### React

::code-group
```tsx [App.tsx]
import { Comark } from '@comark/react'

const content = `# Hello World

This is **markdown** with a custom component:

::alert{type="info"}
Welcome to Comark!
::
`

export default function App() {
  return <Comark>{content}</Comark>
}
```

```html [Output]
<h1 id="hello-world">Hello World</h1>
<p>This is <strong>markdown</strong> with a custom component:</p>
<div class="alert alert-info">
  <p>Welcome to Comark!</p>
</div>
```
::

### HTML (No Framework)

For server-side rendering or static generation without a framework:

::code-group
```typescript [render.ts]
import { parse } from 'comark'
import { renderHTML } from 'comark/string'

const tree = await parse(`# Hello World

This is **markdown** with a custom component:

::alert{type="info"}
Welcome to Comark!
::
`)

const html = renderHTML(tree)
console.log(html)
```

```html [Output]
<h1 id="hello-world">Hello World</h1>
<p>This is <strong>markdown</strong> with a custom component:</p>
<alert type="info">
  <p>Welcome to Comark!</p>
</alert>
```
::

::callout{color="info" icon="i-lucide-info"}
Use the `components` option in `renderHTML` to control how custom components are rendered to HTML. See [HTML Rendering](/rendering/html) for details.
::
