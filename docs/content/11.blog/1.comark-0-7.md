Comark 0.7.0 was released on September 10, 2026. It makes streaming AI output render more cleanly, lets you plug in your own completion rules, and hardens the parser against hostile input. All packages moved to 0.7.0 together.

Comark is an open-source Markdown parser and renderer with components, attributes and plugins. It streams AI output to React, Vue, Svelte, Angular, HTML and the terminal.

## Upgrade

Update every Comark package you use to the same version:

```bash
pnpm add comark@^0.7.0 @comark/vue@^0.7.0
```

Replace `@comark/vue` with your renderer: `@comark/react`, `@comark/svelte`, `@comark/angular`, `@comark/nuxt`, `@comark/html`, or `@comark/ansi`.

## Auto-close follows a spec

A model streams Markdown a few characters at a time, so most frames end inside unfinished syntax. Comark 0.7 rewrites `autoCloseMarkdown()` against a behavioral spec, [`SPEC/auto-close.md`](https://github.com/comarkdown/comark/blob/main/packages/comark/SPEC/auto-close.md), and keeps a linear-time scanner.

The spec covers cases that 0.6 missed:

- **Links and images.** An incomplete link gets the placeholder URL `comark:incomplete-link`, and an incomplete image gets `comark:incomplete-image`. Set `linkMode: 'text-only'` to show the link text without a link.
- **Nested emphasis.** Markers close innermost first: `**bold *italic` becomes `**bold *italic***`.
- **Detached markers stay literal.** `hello **` and `5 * 0` don't turn into emphasis.
- **Math, HTML, setext headings, and tildes.** Block math closes, an incomplete HTML tag at the end is dropped, and a lone `~` is escaped so it can't start a strikethrough.

With `streaming: true`, two helpers stop flicker. `dropTrailingOpeners` drops an opener that the model has only started to type (`hello *` renders as `hello`). The setext guard keeps a short `-` or `=` line from flashing as a heading.

See the [Streaming API](/reference/auto-close) for every option.

## Custom auto-close functions

The `autoClose` option now also accepts a function. It receives the Markdown and returns the string to parse. In streaming mode, it receives only the unstable tail, so incremental parsing still reuses the completed blocks.

A function replaces the default rules, so call `autoCloseMarkdown()` in it to keep them. This example drops a footnote reference that the model hasn't finished, then runs the default rules:

```ts
import { autoCloseMarkdown, parseMarkdown } from 'comark'

const document = await parseMarkdown(markdown, {
  autoClose: (source) => autoCloseMarkdown(source.replace(/\[\^\w*$/, '')),
})
```

## Hardening

A security review found inputs that could hang or crash the parser. Comark 0.7 fixes them, with a regression test for each payload:

- **Denial of service.** Deeply nested inline HTML, huge code highlight ranges, long task-list documents, and large json-render specs no longer block the event loop.
- **Injection.** `renderMarkdown()` round-trips and the stringifier no longer let attribute values break out of their syntax.
- **URL and prop validation.** The [security plugin](/plugins/built-in/security) catches more encoded `javascript:` URLs, keeps `false` boolean props, and rejects non-string `href` and `src` values.
- **Renderer output.** `@comark/html` and `@comark/ansi` escape plugin fallbacks, and the ANSI renderer strips terminal control characters from content.

## Other changes

- **`@comark/ansi`:** `writeAnsi()` and `createAnsiWriter()` are now `printAnsi()` and `createAnsiPrinter()`. The old names still work and print a deprecation note in your editor. They go away in the next major version.
- **`@comark/html`:** void elements use HTML5 style, for example `<br>` instead of `<br />`.
- **Headings:** heading IDs come from the text content only.
- **Components:** children indented under a component marker are no longer dropped.
- **`@comark/angular`:** the package is built with the Angular compiler, so it works in both JIT and AOT apps.

The [full changelog](https://github.com/comarkdown/comark/blob/main/packages/comark/CHANGELOG.md) lists every fix.
